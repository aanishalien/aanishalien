I'm a **Software Engineer — AI Backend** at **OXO**, where I build and harden **CGPShell**, a cross-platform secure exam browser engineered in **C# / .NET (Avalonia UI)** for Windows, macOS, and Linux — covering kiosk-mode security, native OS-level API integration, and production-grade lockdown behavior across three distinct operating systems.

Alongside my core role, I engineer **AI/ML backend systems** — Retrieval-Augmented Generation pipelines, multi-agent architectures, and applied computer vision — with a strong bias toward **shipping production-ready, secure, and scalable software**, not just prototypes.

My engineering philosophy centers on:

- 🏗️ **Systems that hold up in production** — not demos, real cross-platform edge cases
- 🤖 **Applied AI** — RAG, LLM orchestration, agentic workflows, and vector search
- 🔐 **Security-first backend design** — session validation, sandboxing, kiosk-level lockdown
- 🎯 **Product thinking** — engineering decisions tied to real user and business outcomes
